# Summarise donor visibilities

Summarise donor visibilities

## Usage

``` r
vis_statistic(x, w, statistic = c("harmonic", "arithmetic", "median"))
```

## Arguments

- x:

  numeric vector of donor visibility counts

- w:

  numeric vector of donor weights

- statistic:

  one of `"harmonic"`, `"arithmetic"`, `"median"`

## Value

a single number
